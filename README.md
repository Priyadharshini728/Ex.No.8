# Procedure

## 🔹 Step 1: Analyze the Given Image

The image is carefully examined to identify:

* **Objects / Subjects** → Main visual elements
* **Colors** → Dominant shades and contrast
* **Lighting** → Brightness, shadows, reflections
* **Texture** → Smooth, rough, glossy, matte
* **Background** → Indoor or outdoor environment
* **Composition** → Placement and perspective
* **Style** → Realistic, digital art, painting, cartoon

---

## 🔹 Step 2: Create the Basic Prompt

A simple prompt describing the image is written.

### Example:

> “A mountain landscape with a river.”

---

## 🔹 Step 3: Add More Details

The prompt is refined using:

* Color descriptions
* Lighting effects
* Atmosphere
* Background details

### Example:

> “A peaceful mountain landscape during sunset with orange skies and a calm reflective river.”

---

## 🔹 Step 4: Mention the Artistic Style

The image style is added to improve output quality.

### Example:

> “A realistic digital painting of a sunset mountain landscape.”

---

## 🔹 Step 5: Fine-Tune the Prompt

Additional visual effects and mood are included.

### Example:

> “A realistic digital painting of a glowing sunset mountain landscape with soft clouds, warm golden light, and cinematic reflections.”

---

## 🔹 Step 6: Generate the Image

The prompt is entered into AI image generation tools such as:

* DALL·E
* Stable Diffusion
* MidJourney

---

## 🔹 Step 7: Compare and Improve

The generated image is compared with the original image.
If differences are observed, the prompt is refined and regenerated.
